DEEPER OS · 설치 ②

디퍼 OS 깔기

클로드 코드를 내 볼트에 연결했다면, 이제 사막여우를 깔 차례예요. 명령은 딱 세 줄 — 한 줄씩, 아주 천천히 같이 해요. 틀려도 다시 치면 돼요. 🦊

🔑 시작 전에 — 여우의 집은 열쇠로 열려요

사막여우는 살롱 멤버만 드나드는 비공개 저장소에 살아요. 그래서 설치의 첫 줄은 사람마다 달라요 — 살롱이 이메일로 보내드린 ‘나의 설치 한 줄’ 안에 디퍼님 몫의 구독 열쇠가 들어 있거든요.

이 페이지의 첫 줄은 본보기라 열쇠 자리가 비어 있어요. 실제 설치할 땐 꼭 메일의 그 한 줄을 복사해 쓰세요. 메일을 못 찾겠으면 살롱(clbook.slower@gmail.com)에 “설치 한 줄 다시 보내주세요” — 언제든 다시 보내드려요.

시작 전 확인

✅ 옵시디언 볼트를 만들었고  ✅ 클로드 코드가 그 볼트에 연결돼 있나요? (앞 단계 = 클로드 코드 설치 ①)  ✅ 개통 메일이 도착해 있나요? 됐으면 시작해요.

🖥️ ‘터미널’이 처음이세요? (30초만)

터미널은 글로 명령을 시키는 칸이에요. 무섭지 않아요 — 한 줄 치고 Enter가 전부예요. 비밀번호처럼 글자가 안 보여도 정상이고, 틀려도 다시 치면 돼요. 붙여넣기는 🪟 마우스 우클릭(또는 Ctrl+V) · 🍎 Cmd+V.

1
터미널 열기 (앱 안에서)

두 가지 방법 중 아무거나 —

  • 버튼: Code 탭 화면 오른쪽 위 >_ 아이콘(터미널 모양)을 클릭.
  • 단축키: Ctrl + 백틱(맨 왼쪽 위, 숫자 1 왼쪽 · 물결 ~과 같은 키). 🍎 맥도 Ctrl+백틱(Cmd 아니에요).

→ 화면 아래(또는 오른쪽)에 터미널 칸이 열려요. 위에 “터미널”이라고 적혀 있어요.

⚠️ 이건 윈도우 PowerShell·맥 ‘터미널’ 같은 별도 프로그램이 아니라, 클로드 앱 안에 있는 터미널이에요.

2
터미널에 claude 한 단어만

방금 연 터미널 칸에 claude 라고 치고 Enter. (아직 슬래시 명령 아니에요, 딱 이 한 단어.)

대부분 바로 설정 화면이 떠요 → 3번으로.

“claude 인식 안 됨 / not recognized”가 뜨면

클로드 코드가 아직 이 컴퓨터에 없는 거예요. 딱 한 번만 아래 한 줄을 치고 Enter (몇 분이면 깔려요) —

🪟 윈도우:

irm https://claude.ai/install.ps1 | iex

🍎 맥:

curl -fsSL https://claude.ai/install.sh | bash

→ 끝나면 터미널을 닫고 새로 연 다음, 다시 claude → Enter.

3
첫 실행 화면 넘기기 (거의 Enter)

처음 한 번만 설정이 떠요. 거의 Enter로 통과해요 —

  • 테마(색) → 고르고 Enter.
  • 로그인 → 누르면 브라우저가 열려요 → 유료 계정 로그인 → ‘허용/Authorize’ → 터미널로 돌아오기.
  • 깃허브 연결 화면이 나오면 → 지금은 Skip/나중에.
  • 보안 안내 → Enter.
  • “이 폴더를 신뢰?” → Yes / Enter.

→ 화면이 바뀌고 아래에 > 입력 표시가 뜨면, 이제 여기가 ‘클로드 안’이에요(터미널이 클로드로 바뀐 거예요). 🦊

📍 제일 헷갈리는 곳! 어디에 치는지 — 세 칸이 달라요
① ❌Code 탭 채팅창 — 여기선 /plugin이 안 돼요(“isn’t available”).
②터미널 칸(1번에서 연 것) — 여기엔 claude만 쳤어요.
③ ✅그 안에서 실행된 ‘클로드’(> 표시 보이는 곳) — 아래 명령은 꼭 ③ 여기에.
👉 터미널 열기 → claude 실행 → 실행된 클로드 안(>)에 /plugin…
💡 첫 줄은 꼭 ‘메일에서’ 복사하세요

설치 첫 줄엔 디퍼님의 구독 열쇠가 들어 있어서 아주 길어요. 개통 메일에서 그 줄을 통째로 복사(Ctrl+C) → 클로드에 붙여넣기(Ctrl+V) 하면 잘릴 일이 없어요. 폰으로 보고 눈으로 옮겨 치면 긴 열쇠가 잘려 자꾸 실패해요 — 설치하는 그 PC에서 메일을 여세요.

4
클로드 안(>)에서 세 줄, 한 줄씩 Enter

한 줄 치고 Enter, 결과 뜨면 다음 줄 — 이렇게 천천히. 첫 줄은 아래 본보기가 아니라, 개통 메일의 ‘나의 설치 한 줄’을 그대로 붙여넣으세요(열쇠 자리가 이미 채워져 있어요). 맨 끝 .git 까지 전부 들어가야 해요.

/plugin marketplace add https://oauth2:{구독열쇠}@github.com/clbookslower/deeper-os-private.git

↳ 디퍼님의 열쇠로, 여우가 사는 비공개 저장소의 문을 열어요. (위 줄은 본보기 — 진짜 줄은 메일에!)

/plugin install deeper-os@deeper-os

↳ 그 안에서 디퍼 OS를 받아 깔아요.

/reload-plugins

↳ 방금 깐 걸 켜요(새로고침).

중간에 “추가/설치할까요?” 물으면 Yes / Enter.

5
확인 — 사막여우 깨우기

같은 자리(클로드 안)에서 이걸 치고 Enter:

/deeper-os:setup

사막여우가 “제가 뭐라고 불러드릴까요?” 하고 다정하게 인사하며 시작하면 — 설치 성공! 🎉 (사막여우가 폴더·노트 틀을 ‘만들까요?’ 물으면 네 해주세요. 기존 노트는 안 건드려요.)

⚠️ /plugin이 “isn’t available”라고 뜨면

채팅창에 친 거예요. Code 탭 채팅창 말고, 터미널의 claude 안(> 표시 보이는 곳)에서 다시 쳐주세요. (위 ‘세 칸’ 참고.) — 이게 제일 흔한 실수라, 이것만 맞으면 거의 다 돼요.

빨간 글씨로 “CommandNotFoundException / 인식되지 않습니다”가 잔뜩 뜨면 — 터미널(파워셸)에 바로 친 거예요. 고장 아니니 안심하세요. 그 자리에서 claude 한 단어 → Enter로 클로드를 먼저 깨운 뒤(> 표시가 뜨면), 그 안에서 /plugin…을 다시 치면 돼요.

첫 줄에서 “Repository not found / 인증 오류”가 뜨면 — 열쇠가 빠졌거나 잘린 거예요. 개통 메일의 한 줄을 통째로 다시 복사해서 붙여넣어 주세요.

🔄 예전(공개 저장소 시절)에 설치했던 분 — 이사 다섯 줄

여우의 집이 비공개로 이사해서, 옛 주소로는 업데이트가 안 돼요. 볼트·노트·여정 기록은 그대로 두고, 클로드 안(>)에서 아래 다섯 줄을 한 줄씩 — (3번째 줄은 개통 메일의 ‘나의 설치 한 줄’로!)

/plugin uninstall deeper-os@deeper-os
/plugin marketplace remove deeper-os
/plugin marketplace add https://oauth2:{구독열쇠}@github.com/clbookslower/deeper-os-private.git
/plugin install deeper-os@deeper-os
/reload-plugins

끝나면 앱을 껐다 켜고, “안녕” 한마디로 여우가 잘 깨어나는지 확인해 주세요. 노트는 전부 그대로예요.

디퍼 OS 깔기 끝! 🦊
