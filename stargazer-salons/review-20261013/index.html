40% 할인과 40% 가산을 구분합니다

정상가 100을 40% 할인하면 60입니다. 여기에 40%를 더하면 84이므로 원래 가격으로 돌아가지 않습니다. 60에서 100으로 돌아가는 가산율은 66.67%입니다. 84와 60 사이의 할인율은 28.57%입니다. 실제 참가비가 아닌 계산 예시입니다.

첫 기수는 과목별 공개 가격 하나와 기존회원 우선신청을 권고합니다. 일괄 40% 할인은 보류합니다. 실제 할인은 비용을 충당하는지 확인하고 적용 대상·기수·중복 기준을 정한 뒤 도입합니다.

공동 운영몫 10%는 적용 대상부터 정합니다

공동 링크나 유입 코드로 등록 때 확인한 해당 기수 등록에 한해 10%를 적용하는 시범안입니다. 자체 유입·기존 개인 접수·차기 재등록·출처 불명 건에는 소급 부과하지 않습니다. 공동 안내·일정·접수 대조·정산 업무를 맡을 사람이 수락해야 시작합니다.

기준액 = 실제 수납 − 실제 환불 − 증빙으로 확인한 거래별 순 간접세 − 실제 순 결제처리비
대상 등록의 운영몫 = 기준액 × 10%

광고·제작·개인 도구비는 자동 공제하지 않습니다. 추가 공동비는 지출 전에 범위와 부담자를 정합니다. 고객 환불과 정산 조정, 지급일은 별도로 합의합니다. 실제 세금과 결제 계약에 맞춘 확인이 필요합니다.

플랫폼과 결제처리비를 나누어 명시하는 참고 사례로 Maven과 Teachable의 공식 문서를 확인했습니다. 해외의 요율이 우리 운영의 적정 요율을 증명하지는 않습니다.

최소 인원에는 준비·피드백·운영 시간을 넣습니다

준비와 수업, 수강생별 피드백, 공동 운영에 드는 노동을 모두 비용에 넣습니다. 강사와 공동 운영 담당의 비용을 각각 충당하는지 확인합니다. 필요한 인원이 품질을 지킬 정원을 넘으면 가격이나 범위를 조정합니다.

실제 비용·노동시간·수요 자료가 없으므로 일괄 최소 인원이나 적정 가격을 지정하지 않았습니다. 한 명 개강은 부담할 시간과 비용이 확인된 개별 실험으로 판단합니다.
