한 화면에 두 에이전트

Herdr · 아스트라 세팅 안내

정비사에게 맡기는 네 단계입니다.
1·2·3단계는 늘 쓰던 클로드 코드 데스크톱 앱 대화창에서,
터미널은 4단계에 한 번만 엽니다.

먼저 세 가지

  • 「정비사」는 디퍼님 시스템 엔지니어의 이름 자리입니다. 프롬프트 첫 낱말 「정비사님」을 그 이름으로 바꿔 붙여넣으세요.
  • 1·2·3단계 프롬프트는 늘 쓰던 클로드 코드 데스크톱 앱 대화창에 붙여넣습니다. 터미널을 여는 때는 4단계 Herdr 켜기 한 번뿐입니다. API 키를 고른 분만 3단계에서 한 번 더 엽니다. 그 자리는 「터미널을 여는 때」 금색 상자로 표시했습니다.
  • 로그인과 API 키는 정비사가 아니라 디퍼님이 합니다. 정비사가 계정·비밀번호·키를 물으면 대답하지 마세요.

1단계Herdr 설치

늘 쓰던 클로드 코드 데스크톱 앱 대화창에서 정비사를 부르고 아래를 붙여넣습니다.

붙여넣는 곳 · 클로드 코드 데스크톱 앱 대화창
정비사님, Herdr를 설치해 주세요. 터미널을 칸으로 나눠 에이전트 여럿을 한 화면에 두는 도구입니다. 파일 삭제는 하지 마세요. 1. 윈도우는 PowerShell에서 이 한 줄을 실행합니다. powershell -ExecutionPolicy Bypass -c "irm https://herdr.dev/install.ps1 | iex" 맥은 터미널에서 이 한 줄을 실행합니다. curl -fsSL https://herdr.dev/install.sh | sh 2. herdr --version 이 버전 숫자를 내는지 확인합니다. 지금 셸에서 "찾을 수 없다"고 나오면 설치 폴더의 전체 경로로 다시 실행해 보세요. 윈도우는 C:\Users\<사용자이름>\.herdr\packages\standalone\current\herdr.exe 입니다. 3. herdr 자체는 실행하지 마세요. 제가 4단계에서 켭니다. 보고: 운영체제 · herdr --version 결과.

2단계스킬 장착

Herdr 안에 든 사용법 파일을 Claude Code의 스킬 폴더에 둡니다. 그래야 정비사가 Herdr의 칸을 스스로 나눕니다.

붙여넣는 곳 · 클로드 코드 데스크톱 앱 대화창
정비사님, Herdr 스킬을 장착해 주세요. 1. herdr --skill 을 실행하면 스킬 파일 본문이 그대로 출력됩니다. 첫 줄은 --- 이고 둘째 줄은 name: herdr 입니다. 2. 그 출력을 한 글자도 바꾸지 말고 아래 경로에 저장합니다. 폴더가 없으면 만드세요. 윈도우: C:\Users\<사용자이름>\.claude\skills\herdr\SKILL.md 맥: ~/.claude/skills/herdr/SKILL.md UTF-8로, BOM 없이 저장합니다. PowerShell의 > 기호로 저장하지 마세요. UTF-16이 되어 Claude가 읽지 못합니다. 출력을 읽어서 직접 파일로 써 주세요. 보고: 저장 경로 · 파일 첫 다섯 줄.

3단계아스트라 설치와 연결

아스트라는 오픈AI Codex CLI에 붙인 이름입니다. 설치는 정비사가 합니다. 연결은 셋 중 하나입니다. 이미 로그인돼 있으면 그대로 쓰고, 아니면 ChatGPT 로그인이나 API 키로 잇습니다.

붙여넣는 곳 · 클로드 코드 데스크톱 앱 대화창
정비사님, 오픈AI Codex CLI를 설치하고 연결 상태를 확인해 주세요. 계정, 비밀번호, API 키는 묻지도 입력하지도 마세요. 1. 설치 윈도우: node --version 으로 Node.js를 확인합니다. 없으면 winget install OpenJS.NodeJS.LTS 로 설치하고 새 셸을 엽니다. 그다음 npm install -g @openai/codex 를 실행하고 codex.cmd --version 으로 확인합니다. 윈도우에서는 codex 가 아니라 codex.cmd 입니다. 맥: curl -fsSL https://chatgpt.com/codex/install.sh | sh 를 실행하고 codex --version 으로 확인합니다. 2. 연결 확인 codex.cmd login status 를 실행합니다(맥은 codex login status). "Logged in" 이 나오면 이미 연결된 것입니다. 그대로 씁니다. 여기서 끝내고 보고해 주세요. 3. 연결이 안 돼 있으면 저에게 묻습니다. "ChatGPT 로그인으로 할까요, API 키로 할까요?" - ChatGPT 로그인이라고 하면 codex.cmd login 을 실행합니다. 브라우저가 열리면 제가 로그인합니다. 끝났다고 하면 codex.cmd login status 로 확인합니다. - API 키라고 하면 아무것도 실행하지 말고 멈춥니다. 키는 제가 직접 넣습니다. 제가 "넣었어요"라고 하면 codex.cmd login status 로 확인만 합니다. 보고: codex 버전 · login status 결과.
디퍼님이 직접 · ChatGPT 로그인을 고른 경우
  1. 브라우저가 열리면 「Sign in with ChatGPT」로 로그인합니다. 무료 계정도 됩니다.
  2. 정비사에게 "로그인했어요"라고 말합니다.
터미널을 여는 때 · API 키를 고른 경우만
  1. platform.openai.com 에서 API 키를 만들어 복사해 둡니다. 키는 정비사에게 보여 주지 않습니다.
  2. 윈도우 터미널(또는 PowerShell)을 열고 두 줄을 차례로 칩니다. 둘째 줄이 키를 물으면 붙여넣고 Enter. 끝나면 터미널은 닫아도 됩니다.
$k = Read-Host "OpenAI API 키"
$k | codex.cmd login --with-api-key
  1. 맥은 한 줄입니다. read -s k && echo "$k" | codex login --with-api-key
  2. 정비사에게 "넣었어요"라고 말합니다. 키는 내 컴퓨터의 ~/.codex/auth.json에만 남습니다. API 키는 ChatGPT 요금제가 아니라 API 사용량으로 과금됩니다.

4단계한 화면에 두 칸

이 단계만 데스크톱 앱이 아니라 터미널에서 합니다.

터미널을 여는 때 · Herdr 켜고 그 안에서 claude 부르기
  1. 윈도우 터미널(또는 PowerShell)을 열고 세 줄을 차례로 칩니다. 맥은 첫 줄이 cd ~/SecondBrain입니다.
cd C:\SecondBrain
herdr
claude
  1. herdr를 치면 화면이 바뀌고 칸 하나가 뜹니다. 그 칸에서 claude를 칩니다.
  2. 정비사가 대답하면 아래 프롬프트를 이 칸에 붙여넣습니다.
붙여넣는 곳 · Herdr 칸 안에서 연 claude
정비사님, Herdr 스킬로 제 옆 칸에 아스트라(Codex)를 띄워 주세요. 1. HERDR_ENV 값이 1인지 확인하세요. 아니면 멈추고 "Herdr 안에서 claude를 열어 주세요"라고 알려 주세요. 2. 현재 칸을 오른쪽으로 나눕니다. herdr pane split --current --direction right --cwd "C:\SecondBrain" --no-focus (맥은 --cwd "$HOME/SecondBrain") 3. 응답의 pane id로 새 칸에서 아스트라를 읽기 전용으로 실행합니다. 윈도우: herdr pane run "codex.cmd -s read-only --no-alt-screen" 맥: herdr pane run "codex -s read-only --no-alt-screen" 4. herdr pane read --lines 20 으로 화면이 떴는지 확인하고 첫 줄들을 보여 주세요. 5. 쓰기 권한(workspace-write)은 제가 말할 때만, 폴더 하나를 --add-dir 로 지정해서 엽니다. 사막여우 볼트(desertfox)는 언제나 읽기 전용입니다. 보고: pane id · 아스트라 화면 첫 줄들.

왼쪽에 정비사, 오른쪽에 아스트라가 앉아 있으면 끝입니다. 오른쪽 칸을 클릭하면 아스트라에게 바로 말할 수 있습니다.

손으로 다룰 때

Ctrl+B를 누르고 손을 뗀 뒤 다음 글쇠를 누릅니다. 한글 입력 상태면 안 먹습니다.

v 옆으로 나누기
- 아래로 나누기
h j k l 칸 옮겨 다니기
z 이 칸만 크게
x 칸 닫기
q 떼어 두기

다시 들어올 때는 터미널에서 herdr만 치면 떼어 둔 칸이 그대로 있습니다. 완전히 끄려면 herdr server stop입니다.

쓰는 법왼쪽은 손, 오른쪽은 눈

왼쪽 칸의 여우와 정비사가 손일을 합니다. 오른쪽 칸의 아스트라는 읽고 견주고 빠진 곳을 짚습니다. ChatGPT 로그인이면 한도가 빨리 줄어드니 판단에만 씁니다. 판단은 파일로 받아 왼쪽에 넘깁니다.

"C:\SecondBrain\agents\CLAUDE.md 를 읽고 기둥 문장끼리 부딪히는 자리가 있는지 봐 줘. 고치지는 말고 어느 줄과 어느 줄이 부딪히는지만 적어 줘. 다 보면 C:\SecondBrain\agents\system\일지\2026-09-08_아스트라.md 에 남기고 파일 경로 한 줄만 답해 줘."

경계

  • 로그인과 API 키는 나. 정비사는 브라우저만 엽니다.
  • 아스트라는 읽기 전용으로 시작합니다. 쓰기는 폴더 하나씩, 말할 때만.
  • 사막여우 볼트는 아스트라에게 늘 읽기 전용입니다.
  • 열쇠와 비밀번호는 채팅창에 적지 않습니다.
