무엇을 만드는가
나만의 세컨브레인

“뭐 하는지 모르겠어요.” 그 물음에 정면으로 답하는 자리입니다. 우리가 지금 만드는 게 정확히 무엇인지, 딱 한 번만 짚고 갑니다.

이것 하나만 기억하시면 됩니다.

우리가 만드는 것

내가 매일 몇 줄 적으면, 그게 나만 아는 것들을 모아 둔 작은 사전이 됩니다. 그리고 AI가 그 사전을 옆에서 계속 읽어 줍니다.

하루하루 적을수록 사전이 두꺼워지고, 시간이 갈수록 나에게 더 쓸모 있어집니다. 살롱이 끝나도 이 사전은 사라지지 않고 내 컴퓨터에 남습니다.

이걸 세컨브레인(제2의 뇌)이라 부릅니다. 그리고 그 사전을 부르는 다른 이름이 언어모델 위키예요. 내 데이터가 쌓여 AI가 그 위에서 나를 이해하는 구조를 가리키는 말입니다. 나머지 낯선 말들은 다 이 하나를 만들기 위한 도구 이름일 뿐입니다.

보통 챗봇과 무엇이 다른가

보통 챗봇

매번 새 대화입니다. 나를 기억하지 못해서, “나는 누구고 뭘 한다”를 늘 다시 설명해야 합니다.

사막여우

내 노트 폴더를 직접 봅니다. 그래서 나를 기억하고, 내가 쌓은 글을 읽고, 새 노트를 만들어 저장합니다. 복붙이 없어요.

사막여우는 우리 모두의 공통 동반자입니다. 문법의 달을 함께 걷는 여우 한 마리 — 이름은 다 같이 ‘사막여우’로 키웁니다.

우리가 쓰는 것, 여섯 개

실제로 깔아야 하는 건 셋뿐입니다. 나머지 셋은 이름만 알아 두면 돼요.

도구한 줄로 뭔가요지금 필요?
옵시디언내 글이 텍스트 파일로 쌓이는 무료 노트 앱 (메모장 같은 것)지금 설치
클로드 코드
(Code 탭)		내 옵시디언 폴더를 직접 읽고 쓰는 AI. 사막여우가 사는 자리지금 설치
사막여우
(디퍼 OS)		Code 탭에 까는 프로그램. 매일 루틴·질문·30일 여정을 얹어 줌지금 설치
클로드 챗
(claude.ai)		파일 없이 빠르게 대화만 하는 일반 챗봇나중에
코워크
(Cowork)		오래 걸리는 일(리서치 등)을 맡기는 도우미나중에
언어모델 위키도구가 아니라 개념. 위에서 말한 “나만의 사전”을 부르는 말개념

즉, 지금 설치하는 건 옵시디언 · Code 탭 · 사막여우 셋입니다. 클로드 챗·코워크는 익숙해진 뒤에, 언어모델 위키는 그냥 알아만 두시면 됩니다.

세 자리를 같이 쓰는 법 (나중에)

클로드에는 세 자리가 있습니다. 지금은 Code만 쓰지만, 나중을 위해 한 번만 짚어 둡니다.

Code (본진)
내 볼트를 읽고 쓰고, 나를 기억합니다. 남길 작업은 전부 여기.
Chat
파일 없이 빠른 대화. 좋은 답이 나오면 Code로 가져옵니다.
Cowork
오래 걸리는 일을 맡기는 도우미. 폴더를 읽고 로컬에 저장도 됩니다.

세 자리는 서로 기억을 공유하지 않아요. 좋은 결과는 복사해 Code의 사막여우에게 붙여넣고 “정리해줘”. 최종 자산은 늘 Code에 남깁니다.
