진영님 맥북 이사 가이드
— 미니동킴에게 세 번만 시키면 끝

병원 공용 노트북의 세컨드브레인(사막여우 볼트 + 에이전트 + 작업물)을 새 맥북으로 옮기고, 공용 노트북은 흔적 없이 비웁니다. 실무는 전부 비서 미니동킴이 합니다. 진영님이 하실 일은 심부름 세 번 시키기, USB 꽂기, 그리고 몇 번의 승인뿐이에요.

대원칙 — 삭제는 맨 마지막. 공용 노트북의 어떤 것도, 맥북에서 살아 움직이는 걸 확인하기 전에는 지우지 않습니다. 미니동킴도 이 원칙을 지키도록 심부름 문안에 박아뒀습니다.
심부름 ①공용 노트북 — 짐 싸기 기초 공사새 맥북 — 앱 설치 5가지 심부름 ②맥북 — 짐 풀기 심부름 ③공용 노트북 — 비우기 §안전선 — HIPAA·재정 §맥 메시지 · 슬랙 가이드

심부름 ① · 공용 노트북에서짐 싸기 — 조사부터 포장까지 미니동킴이

공용 노트북에서 클로드 코드를 열고 미니동킴을 불러, 아래를 통째로 붙여넣으세요. 조사 → 볼트 백업 → 민감자료 포장까지 한 번에 진행하고, 중간중간 진영님께 확인을 받습니다.

미니동킴에게 붙여넣기 ① — 짐 싸기
미니동킴, 컴퓨터 이사를 너에게 처음부터 끝까지 맡길게. 이 공용 노트북의 내 작업 전부를 새 맥북으로 옮기고, 이 컴퓨터는 나중에 깨끗이 비울 거야. 오늘은 1단계 "짐 싸기"만 한다. 아직 아무것도 지우지 마. [1. 짐 조사] - 사막여우 볼트(desert-fox) 폴더 위치, 파일 수, 용량. 깃 상태(커밋 안 된 변경, 마지막 푸시 시각)도 확인. - .gitignore로 깃에서 제외된 폴더·파일 전부 찾기. (재정 보안폴더가 여기 있어 — 경로와 파일 수를 정확히) - agents 폴더 위치와 내용물. - 다운로드·바탕화면·문서 폴더에서 최근 6개월 내 업무 파일. - 이 컴퓨터에 로그인된 흔적(깃허브 자격 증명, 클로드 코드, 브라우저). - 전부를 "이사목록.md"로 정리: ①깃으로 갈 짐 ②USB로 갈 짐 ③옮기지 않고 지우기만 할 것. [2. 볼트 백업] - 이사목록을 나에게 보여주고 내가 확인하면, 볼트의 모든 변경사항을 커밋하고 깃허브 비공개 백업에 푸시해. 푸시가 최신인지 검증까지. [3. 민감자료 포장] - ②USB로 갈 짐(보안폴더·agents 폴더·흩어진 파일)을 암호 걸린 zip 하나로 만들어. 암호는 강하게 만들어서 나한테 딱 한 번 보여줘 — 내가 폰에 옮겨 적을게. 이사목록.md도 zip에 같이 넣어. - zip이 완성되면 USB에 복사하는 것까지 안내해줘. 각 단계가 끝날 때마다 뭘 했는지 짧게 보고하고, 판단이 필요한 건 임의로 정하지 말고 나에게 물어봐.
진영님 손이 필요한 순간 — ① 이사목록 훑어보고 "진행해" 한마디 ② zip 암호를 폰 메모에 옮겨 적기 ③ USB 꽂기. 이게 전부입니다.

재정 등 민감자료가 USB로 가는 이유

보안폴더는 일부러 깃에서 빼놓은 자료라 깃허브 백업에 실리지 않습니다(그게 정상). 그래서 이 짐만은 암호 zip + USB 손 이동입니다. 클라우드·이메일·카톡에 올리지 마세요 — 병원 공용 계정과 무료 클라우드에는 흔적이 남습니다.

기초 공사 · 새 맥북에서앱 설치 다섯 가지 — 여기만 손으로

새 맥북엔 아직 아무것도 없으니, 이 다섯 가지만 진영님이 직접 설치합니다. 순서대로 15분이면 끝나요. 이게 끝나면 나머지는 다시 에이전트의 일입니다.

  1. 클로드 데스크탑 앱 — 브라우저에서 claude.ai/download → Mac용 내려받기 → 응용 프로그램에 넣고 실행 → 로그인.
  2. git — 터미널을 엽니다(Spotlight에서 ⌘+스페이스 → "터미널" 입력). 아래 한 줄을 붙여넣고 엔터:
    git --version
    처음이면 "명령어 라인 개발자 도구를 설치하겠습니까?" 창이 뜹니다 → 설치 클릭. (이게 맥의 git 설치 방식이에요. 이미 있으면 버전 숫자가 나오고 끝.)
  3. 옵시디언(Obsidian) — obsidian.md에서 Mac용 내려받기 → 응용 프로그램에 넣기. (볼트 열기는 짐 풀기가 끝난 뒤에 — 아래에서 안내)
  4. 클로드 코드(터미널용) — 터미널에 아래 한 줄을 붙여넣고 엔터:
    curl -fsSL https://claude.ai/install.sh | bash
    끝나면 터미널을 껐다 켜고 claude 입력. 그다음은 여섯 관문을 순서대로 지나갑니다:
    1. 글자 스타일(테마) 고르기 — 마음에 드는 것에 두고 그냥 엔터 (다크 모드 추천)
    2. "Use Claude Code's terminal setup?" — 1번(Yes, 추천 설정)에서 엔터
    3. 로그인 방법 — 1번 (Claude account with subscription) 선택하고 엔터
    4. 그 순간 브라우저가 저절로 열리며 claude.ai 로그인 페이지가 뜹니다 — 평소 클로드 앱 쓰던 계정으로 로그인 → Authorize(승인) 클릭
    5. 화면에 코드(긴 글자열)가 나오면 복사해서 터미널에 붙여넣고 엔터 (코드 없이 바로 성공이 뜨면 건너뜀)
    6. "Login successful" 후 시키는 대로 엔터 몇 번, 폴더를 신뢰하냐고 물으면 Yes — 터미널에 > 입력창이 뜨면 준비 완료

    🔧 claude를 쳤는데 "command not found"가 나오면

    설치는 됐는데 터미널이 클로드의 주소를 아직 모르는 것뿐입니다(새 맥에서 흔한 일 — 껐다 켜도 안 풀립니다). 아래 한 줄을 통째로 붙여넣고 엔터 한 번이면 주소 등록부터 실행까지 한 번에 됩니다:

    [ -x ~/.local/bin/claude ] || curl -fsSL https://claude.ai/install.sh | bash; echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc; source ~/.zshrc; claude
  5. USB 꽂기 — 심부름 ①에서 싼 짐(암호 zip)이 든 USB를 꽂아둡니다.
여기까지 되면 — 맥북에 클로드(앱+터미널)·git·옵시디언이 갖춰졌습니다. 이제 심부름 ②를 시키면 됩니다.

심부름 ② · 새 맥북에서짐 풀기 — 복원부터 검증까지 미니동킴이

터미널에서 claude를 실행하거나 클로드 데스크탑 앱의 Code 탭을 열고, 아래를 붙여넣으세요. 미니동킴이 아직 맥북에 없어도 괜찮습니다 — 이 심부름을 받은 클로드가 agents 폴더를 복원하는 순간 미니동킴도 함께 돌아옵니다.

데스크탑 앱 Code 탭으로 할 때 — "폴더 선택" 창이 뜨면

  • Code 탭은 시작할 때 "어느 폴더에서 일할까?"를 묻는 폴더 선택창을 띄웁니다. 새 폴더를 만들지 마세요 — 왼쪽 목록에서 Documents(문서)를 한 번 클릭하고 오른쪽 아래 Open을 누르면 끝입니다.
  • 볼트 폴더는 클로드가 짐을 풀면서 옛 컴퓨터와 같은 이름으로 알아서 만듭니다. 미리 빈 폴더를 만들어 지정하면 폴더 속 폴더로 겹쳐질 수 있어요.
  • 환경은 Local을 씁니다(Cloud 아님). 로그인·디퍼 OS 설치는 터미널과 데스크탑 앱이 함께 쓰므로 한 번만 하면 양쪽에 다 삽니다.

USB가 아직 없어도 시작할 수 있어요

아래 심부름의 1번(깃허브에서 볼트 내려받기)은 USB 없이도 됩니다. 클로드가 USB를 찾으면 "USB는 나중에, 1번부터 해줘"라고 말하면 돼요. zip 풀기(2번)만 USB가 도착한 뒤에 이어서 하면 됩니다. 급하다고 재정 zip을 클라우드·이메일로 보내지는 마세요 — 그 짐만은 끝까지 손 이동입니다.

맥북 클로드 코드에 붙여넣기 ② — 짐 풀기
새 맥북이야. 공용 노트북에서 이사 온 짐을 풀어줘. USB에 암호 zip이 있고, 그 안의 "이사목록.md"가 짐 목록의 기준이야. 1. 깃허브 로그인을 확인하고, 내 사막여우 백업 저장소를 문서 폴더 아래에 클론해줘. 2. USB의 zip을 풀어서(암호는 내가 입력할게) 이사목록.md 구조 그대로 배치해줘 — 보안폴더는 원래의 상대 위치에, agents 폴더도 제자리에. 3. 검증: 풀린 파일 수·용량이 이사목록.md의 숫자와 맞는지 대조해서 보고해줘. 4. 한글 파일명이 깨져 보이거나 깃이 전체 파일을 변경으로 잡으면, 맥 한글 자소 분리 문제야 — git config core.precomposeUnicode true 적용하고 상태를 다시 확인해줘. 5. 다시 로그인해야 할 것들(깃허브·Gmail 연동·MCP)을 목록으로 주고, 하나씩 같이 진행하자. 6. 끝나면 미니동킴으로 깨어나서, 어제까지의 기록이 다 있는지 너의 눈으로 최종 확인하고 보고해줘. 7. zip 원본은 아직 USB에 그대로 둬 — 소거는 다음 단계에서 한다.
진영님 손이 필요한 순간 — ① zip 암호 입력 ② 로그인 3종 클릭(깃허브·Gmail·MCP는 기기별이라 새로 해야 합니다).

이사 완료 검증 — 네 가지가 다 "예"여야 심부름 ③으로

짐을 다 풀었으면 — 볼트에 옷 입히기 (옵시디언 + 디퍼 OS)

  1. 옵시디언으로 볼트 열기 — 옵시디언 실행 → "Open folder as vault(폴더를 보관함으로 열기)" → 방금 클론한 사막여우 볼트 폴더 선택. 처음 열면 "이 볼트의 제작자를 신뢰하시겠습니까?" 같은 확인창이 뜹니다 — 신뢰(Trust author and enable plugins)를 누르세요(진영님 본인의 볼트니까요). 어제까지의 노트가 그대로 보이면 성공.
  2. 디퍼 OS 설치 — 열쇠로 :

    🔑 열쇠는 이 가이드에 없습니다

    • 디퍼 OS 설치 열쇠(/plugin으로 시작하는 한 줄)는 퍼핀이 카톡으로 따로 보냅니다. 열쇠는 구독자 개인 것이라 공개 문서에 싣지 않아요.
    • 받은 줄은 링크를 누르는 게 아니라 글자를 통째로 복사합니다(길게 누르기/우클릭 → 복사). 답장-인용으로 다시 받은 건 뒤가 잘릴 수 있으니 처음 온 원본 메시지에서 복사하세요.
    • 붙여넣는 자리는 터미널 맨바닥(%)이 아니라 claude가 켜진 화면의 > 입력창입니다. 붙인 뒤 줄 끝이 deeper-os-private.git으로 끝나는지 확인하고 엔터.
    • "Successfully added marketplace" 가 나오면 이어서 두 줄을 하나씩: /plugin install deeper-os@deeper-os → /reload-plugins
    • 끝나면 claude를 껐다 켜고(/exit 후 다시 claude) "사막여우 안녕" — 여우가 대답하면 설치 성공. 볼트가 아직 없으면 "못 찾겠다"고 하는 게 정상이니, "새로 만들까요?"에는 만들지 말고 "아직 이사 전"이라고만 답하세요.

심부름 ③ · 다시 공용 노트북에서비우기 — 흔적까지 미니동킴이

병원 공용 노트북은 다음 사람이 씁니다. 폴더 삭제만으로는 부족해요 — 대화 기록과 로그인 흔적이 진짜 소거 대상입니다. 위 검증 4개를 모두 마친 뒤에만 진행하세요.

공용 노트북의 미니동킴에게 붙여넣기 ③ — 비우기
미니동킴, 이사가 끝났고 맥북에서 전부 확인했어. 이제 이 컴퓨터를 깨끗이 비워줘. 이사목록.md 기준으로, 하나 지울 때마다 뭘 지웠는지 보고하면서 진행해. 1. desert-fox 볼트 폴더, agents 폴더, 보안폴더 삭제. 2. 다운로드·바탕화면·문서의 내 업무 파일 삭제(목록의 ③ 묶음 포함). 3. 사용자 폴더의 .claude 폴더 삭제 — 우리 대화 기록이 여기 있어. (이걸 지우면 너와의 기록도 이 컴퓨터에선 사라져. 맥북에 새 집이 있으니 괜찮아.) 4. 깃 자격 증명 삭제 — Windows 자격 증명 관리자의 github 항목, .gitconfig, .ssh 폴더의 내 키. 5. 이사 때 만든 zip과 임시 파일 삭제, 휴지통 비우기. 6. 내 이름과 계정명으로 전체 검색해서 남은 파일이 없는지 마지막 점검. 7. 브라우저는 내가 직접 할게 — 로그아웃할 계정과 지울 저장 항목을 목록으로 줘.

안전선병원에서 AI를 쓰는 두 개의 금

① 환자 정보(PHI)는 AI 도구에 넣지 않는다 — HIPAA

  • 환자 이름·연락처·진료 내용이 식별되는 형태로 클로드·볼트·슬랙에 들어가면 안 됩니다. (BAA 계약이 있는 엔터프라이즈 환경이 아닌 한)
  • 미니동킴이 다루는 것은 운영 정보까지만 — "오늘 리콜 12건, 명단은 병원 시스템에서 확인" ⭕ / "김OO님 임플란트 재예약" ❌
  • 환자에게 가는 문자·리마인더는 병원의 HIPAA 준수 시스템(기존 PMS·문자 서비스)으로. 클로드는 그 문안을 다듬는 데까지.

② 재정·계약 자료는 볼트의 보안폴더에만

  • 지금처럼 깃 제외 보안폴더 방식 유지 — 깃허브 백업에 안 올라가는 게 정상입니다. (그래서 이사 때 USB로 옮긴 것)
  • 공용 컴퓨터에는 다시 만들지 않기. 이제 이 시스템의 집은 진영님 맥북 하나입니다.
  • 보안폴더의 별도 백업이 필요하면 암호 zip + 외장 저장장치로, 분기에 한 번이면 충분합니다.

맥북에서 열리는 것메시지와 슬랙 — 직원 소통 세팅

이메일은 이미 쓰고 계시니, 맥북이 와서 새로 열리는 두 갈래만 정리합니다. 공통 원칙은 하나 — 초안은 미니동킴이, 전송 승인은 진영님이. 클로드는 승인 없이 남의 명의로 메시지를 보내지 않습니다.

맥의 메시지(iMessage·문자)

  1. 준비 : 맥의 Messages 앱에 Apple ID 로그인. 일반 문자(SMS)까지 보내려면 아이폰에서 설정 → 메시지 → 문자 메시지 전달(Text Message Forwarding)에서 맥북을 켭니다.
  2. 사용 : 미니동킴이 화면 제어로 Messages 앱을 다룹니다. "프런트 리사에게 내일 오전 스케줄 변경 문자 초안 잡아줘" → 초안 확인 → 승인하면 전송.
  3. 알맞은 용도 : 직원 개인에게 가는 짧은 연락. 대량 발송·환자 문자에는 쓰지 않기 — 환자 연락은 병원 시스템으로(위 안전선 ①).
  4. 화면 제어는 이메일·슬랙보다 손이 느리고 오작동 여지가 있어, 셋 중 보조 수단으로 두는 걸 권합니다.

슬랙 — 직원 소통의 본진으로

  1. 워크스페이스 만들기 : slack.com에서 병원 워크스페이스 생성(무료 플랜으로 충분) → 직원 초대 → 채널은 단순하게: #공지 #프런트 #진료실 정도.
  2. 클로드와 연결 : claude.ai 커넥터 설정에서 Slack을 연결하거나, 클로드 코드에서 /mcp로 Slack 연동을 추가하고 브라우저에서 승인. 한 번 연결하면 계속 갑니다. (막히면 미니동킴에게 "슬랙 연결 도와줘" — 단계별로 안내합니다)
  3. 쓰는 패턴 세 가지 :
    • 아침 브리핑 — "오늘 스케줄 요약해서 #공지 초안 잡아줘" → 승인 → 게시
    • 업무 지시 — "재고 주문 건, 프런트 채널에 부탁 메시지로" → 승인 → 전송
    • 회의 정리 — 회의 메모를 주고 "결정사항만 추려 #공지에" → 승인 → 게시
  4. 채널 규칙 한 줄을 첫 공지로 박아두세요 : "슬랙에는 환자 성함·진료 내용을 쓰지 않습니다. 환자 건은 병원 시스템에서."

요약 — ① 공용 노트북에서 짐 싸기(조사·백업·암호 zip) → 맥북 기초 공사(앱 5가지, 15분) → ② 짐 풀기(복원·검증·재로그인) + 옵시디언·디퍼 OS(열쇠는 카톡으로) → ③ 공용 노트북 비우기(파일·대화 기록·자격 증명까지). 실무는 미니동킴, 진영님은 설치·USB·승인만. 삭제는 언제나 맥북 검증 후에.
