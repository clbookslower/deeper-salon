진영님 맥북 이사 가이드
— 사막여우와 짐 전부, 안전하게

병원 공용 노트북에서 돌리던 디퍼 OS(사막여우 볼트 + 에이전트)와 작업물 전부를 새 맥북으로 옮기고, 공용 노트북은 흔적 없이 비우는 전 과정입니다. 순서대로만 가면 됩니다.

대원칙 — 삭제는 맨 마지막. 공용 노트북의 어떤 것도, 맥북에서 살아 움직이는 걸 두 눈으로 확인하기 전에는 지우지 않습니다.

먼저, 핵심 질문"사막출발 → 사막도착"만 하면 될까?

뼈대는 됩니다. 그러나 그것만 하면 짐의 절반이 남습니다.

"사막출발"은 사막여우 볼트(desert-fox 폴더)를 깃허브 비공개 백업에 실어 보내고, "사막도착"은 새 컴퓨터에서 그걸 내려받는 장치입니다. 즉 깃(git)이 추적하는 볼트 안의 기록은 완벽하게 옮겨집니다. 문제는 깃 밖에 사는 것들입니다.

이 가이드의 1~3막은 이 표의 여섯 줄을 하나도 빠뜨리지 않기 위한 순서입니다.

1막 · 공용 노트북에서짐 조사 — 에이전트에게 시키기

손으로 뒤지지 마세요. 공용 노트북의 클로드 코드를 열고, 아래를 그대로 붙여넣으면 에이전트가 이삿짐 목록을 만들어 줍니다.

붙여넣기 ① — 이삿짐 전수조사
컴퓨터 이사 준비를 도와줘. 나는 이 컴퓨터의 모든 작업물을 새 맥북으로 옮기고 이 컴퓨터는 깨끗이 비울 거야. 아래를 조사해서 "이사목록.md" 파일로 정리해줘. 1. 사막여우 볼트(desert-fox) 폴더의 위치, 전체 파일 수와 용량. 깃 상태도 확인해줘 — 커밋 안 된 변경이 있는지, 마지막 푸시가 언제인지. 2. 볼트 안팎에서 .gitignore로 깃에서 제외된 폴더·파일을 전부 찾아줘. (보안폴더·재정 자료가 여기 있을 거야 — 경로와 파일 수를 적어줘) 3. agents 폴더의 위치와 내용물 목록. 4. 다운로드·바탕화면·문서 폴더에서 최근 6개월 내 만들어진 업무 관련 파일(문서·스프레드시트·PDF·이미지)을 찾아 목록으로. 5. 이 컴퓨터에 로그인된 계정 흔적을 정리해줘 — 깃허브 자격 증명, 클로드 코드 로그인, 브라우저에 저장된 로그인. 6. 위 전부를 ①깃으로 갈 짐 ②손으로 옮길 짐 ③옮기지 않고 지우기만 할 것, 세 묶음으로 나눠서 정리해줘. 아직 아무것도 옮기거나 지우지 마. 목록만.

나온 이사목록.md를 한 번 훑어보세요. 특히 ②손으로 옮길 짐 묶음에 재정 보안폴더와 agents 폴더가 들어 있는지 — 이 확인이 1막의 전부입니다.

2막 · 이사 실행세 갈래로 나눠 옮기기

A. 볼트 — "사막출발"

  • 공용 노트북에서 사막여우에게 "사막출발" — 커밋 안 된 기록까지 전부 실어 깃허브 비공개 백업에 푸시합니다.
  • 끝나면 에이전트에게 "푸시가 최신인지 확인해줘"라고 한 번 더 — 마지막 커밋 시각이 방금이어야 합니다.

B. 깃 밖의 짐 — 손 이사 (보안폴더 · agents 폴더 · 흩어진 파일)

재정 등 민감자료의 이동 규칙

  • 클라우드·이메일·카톡으로 보내지 않기. 병원 공용 계정이나 무료 클라우드에 재정 파일이 스치기만 해도 흔적이 남습니다.
  • 방법: 에이전트에게 "②손으로 옮길 짐 묶음을 암호 걸린 zip 하나로 만들어줘" → USB 메모리에 담아 → 맥북에서 풀기 → 확인 후 USB도 비우기.
  • zip 암호는 파일과 다른 경로로(직접 기억하거나 문자로).

옮긴 뒤 맥북에서 "zip을 푼 결과의 파일 수·용량이 이사목록.md의 숫자와 맞는지 대조해줘"라고 시키면 검증까지 끝납니다.

C. 맥북 도착 세팅

  1. 맥북에 클로드 코드(데스크탑 앱) 설치 → 로그인.
  2. 깃허브 로그인 후, 사막여우 백업 저장소를 원하는 위치에 git clone. (에이전트에게 "내 사막여우 백업 저장소를 클론해줘"라고 해도 됩니다)
  3. 클론한 볼트 폴더에서 "사막도착" — 여정·기록이 그대로 이어집니다.
  4. USB의 보안폴더·agents 폴더를 원래 있던 상대 위치에 풀어 넣기. (에이전트에게 이사목록.md를 보여주며 "이 구조대로 배치해줘")
  5. 재로그인 3종 — 깃허브, Gmail 연동, 쓰던 MCP 연동. 로그인은 기기별이라 새로 해야 합니다.
  6. ⚠️ 한글 파일명 주의 — 윈도우→맥 이사에서 한글 자모가 풀려 보이거나 깃이 전체 파일을 변경으로 잡는 일이 가끔 있습니다. 증상이 보이면 에이전트에게 "맥 한글 자소 분리 문제야. git config core.precomposeUnicode true 적용하고 상태 다시 봐줘"라고 하면 됩니다.

이사 완료 검증 — 이 네 가지가 다 "예"면 3막으로

3막 · 공용 노트북에서흔적 없이 비우기

병원 공용 노트북은 다음 사람이 씁니다. 폴더 삭제만으로는 부족합니다 — 대화 기록과 로그인 흔적이 진짜 소거 대상입니다.

붙여넣기 ② — 소거 (검증 체크 4개를 모두 마친 뒤에만)
이사가 끝났고 맥북에서 전부 확인했어. 이제 이 컴퓨터를 깨끗이 비워줘. 이사목록.md를 기준으로, 하나 지울 때마다 뭘 지웠는지 보고해줘. 1. desert-fox 볼트 폴더, agents 폴더, 보안폴더 삭제. 2. 다운로드·바탕화면·문서의 내 업무 파일 삭제 (목록의 ③번 묶음 포함). 3. 사용자 폴더의 .claude 폴더 삭제 — 대화 기록·세션이 여기 있어. 4. 깃 자격 증명 삭제 — Windows 자격 증명 관리자에서 github 항목, 그리고 .gitconfig와 .ssh 폴더의 내 키. 5. 압축했던 zip 파일과 임시 파일 삭제. 6. 휴지통 비우기. 7. 마지막으로 내 이름·계정으로 검색해서 남은 파일이 없는지 훑어줘. 브라우저는 네가 알려주면 내가 직접 할게 — 로그아웃해야 할 계정과 지워야 할 저장 항목을 목록으로 줘.

브라우저·계정은 손으로 (에이전트가 목록을 주면)

안전선병원에서 AI를 쓰는 두 개의 금

① 환자 정보(PHI)는 AI 도구에 넣지 않는다 — HIPAA

  • 환자 이름·연락처·진료 내용이 식별되는 형태로 클로드·볼트·슬랙에 들어가면 안 됩니다. (BAA 계약이 있는 엔터프라이즈 환경이 아닌 한)
  • 에이전트가 다루는 것은 운영 정보까지만 — "오늘 리콜 12건, 명단은 병원 시스템에서 확인" ⭕ / "김OO님 임플란트 재예약" ❌
  • 환자에게 가는 문자·리마인더는 병원의 HIPAA 준수 시스템(기존 PMS·문자 서비스)으로. 클로드는 그 문안을 다듬는 데까지.

② 재정·계약 자료는 볼트의 보안폴더에만

  • 지금처럼 깃 제외 보안폴더 방식 유지 — 깃허브 백업에도 안 올라가는 게 정상입니다. (그래서 이사 때 손으로 옮긴 것)
  • 공용 컴퓨터에는 다시 만들지 않기. 이제 이 시스템의 집은 진영님 맥북 하나입니다.
  • 보안폴더의 별도 백업이 필요하면 암호 zip + 외장 저장장치로, 분기에 한 번이면 충분합니다.

맥북에서 열리는 것메시지와 슬랙 — 직원 소통 세팅

이메일은 이미 쓰고 계시니, 맥북이 와서 새로 열리는 두 갈래만 정리합니다. 공통 원칙은 하나 — 초안은 에이전트가, 전송 승인은 진영님이. 클로드는 승인 없이 남의 명의로 메시지를 보내지 않습니다.

맥의 메시지(iMessage·문자)

  1. 준비 : 맥의 Messages 앱에 Apple ID 로그인. 일반 문자(SMS)까지 보내려면 아이폰에서 설정 → 메시지 → 문자 메시지 전달(Text Message Forwarding)에서 맥북을 켭니다.
  2. 사용 : 클로드 코드가 화면 제어로 Messages 앱을 다룹니다. "프런트 리사에게 내일 오전 스케줄 변경 문자 초안 잡아줘" → 초안 확인 → 승인하면 전송.
  3. 알맞은 용도 : 직원 개인에게 가는 짧은 연락. 대량 발송·환자 문자에는 쓰지 않기 — 환자 연락은 병원 시스템으로(위 안전선 ①).
  4. 화면 제어는 이메일·슬랙보다 손이 느리고 오작동 여지가 있어, 셋 중 보조 수단으로 두는 걸 권합니다.

슬랙 — 직원 소통의 본진으로

  1. 워크스페이스 만들기 : slack.com에서 병원 워크스페이스 생성(무료 플랜으로 충분) → 직원 초대 → 채널은 단순하게: #공지 #프런트 #진료실 정도.
  2. 클로드 코드와 연결 : claude.ai 커넥터 설정에서 Slack을 연결하거나, 클로드 코드에서 /mcp로 Slack 연동을 추가하고 브라우저에서 승인. 한 번 연결하면 계속 갑니다. (막히면 에이전트에게 "슬랙 MCP 연결 도와줘" — 단계별로 안내합니다)
  3. 쓰는 패턴 세 가지 :
    • 아침 브리핑 — "오늘 스케줄 요약해서 #공지 초안 잡아줘" → 승인 → 게시
    • 업무 지시 — "재고 주문 건, 프런트 채널에 부탁 메시지로" → 승인 → 전송
    • 회의 정리 — 회의 메모를 주고 "결정사항만 추려 #공지에" → 승인 → 게시
  4. 채널 규칙 한 줄을 첫 공지로 박아두세요 : "슬랙에는 환자 성함·진료 내용을 쓰지 않습니다. 환자 건은 병원 시스템에서."

요약 — 사막출발·도착은 볼트만 옮깁니다. 보안폴더·agents 폴더·흩어진 파일은 암호 zip+USB로, 로그인은 새로, 공용 노트북은 대화 기록(.claude)과 자격 증명까지 지워야 끝. 삭제는 맥북 검증 후에만.
