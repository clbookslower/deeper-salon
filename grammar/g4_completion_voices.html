1

《생각하는 기계》가 촉발한 질문들

오늘은 문법의 마지막 세션입니다. 한 달이 길기도 했고, 눈 깜짝할 사이이기도 했습니다. 세션의 첫 자리는 책 나눔입니다 — 지난 한 주의 근황과 함께, 책에서 가져온 인사이트를 나눕니다.

함께 읽은 책은 《생각하는 기계》 — 젠슨 황과 엔비디아의 이야기입니다. 기술 경영서로 분류되지만, 이 살롱에서는 '비전을 가진 사람의 태도', '형편없는 것을 내놓을 자유', '두려움과 기대가 공존하는 시대를 사는 법'에 대한 책으로 읽습니다.

나눔 질문 · 한 사람씩

책에서 가장 오래 머문 대목은 어디였나요. 그 대목이 지금 나의 한 달과 어디에서 만나나요. 두려움과 기대가 공존한다면 — 그 두 마음을 그대로 꺼내놓아도 됩니다.

젠슨 황이 엔지니어링하는 대상은 자기 자신이다.

《생각하는 기계》 434쪽 · 당시 엔지니어의 말

결국 이 책이 말하는 것은 하나입니다. 가장 앞선 기술을 다루려면 비전이 있어야 한다는 것. 세상이 몽상이라 치부하던 꿈이, 결정적인 순간마다 어떤 힘으로 작용했는지를 이 책은 구체적으로 보여줍니다.

Today's Core Insight

AI가 아무리 발전해도, 유기적 생명이 진화해온 방식처럼 — 살아남는 것은 꿈꾸는 자다. 실행은 에이전트가 한다. 꿈은 내가 꿔야 한다.

2

씨앗의 이름 — 기호로 전달하는 일

오늘의 강의 주제는 '씨앗의 이름'입니다. 지난 3주 동안 발굴한 원천 텍스트, 목소리의 결, 콘텐츠 지형도 — 이 모든 것이 이제 하나의 이름으로 묶입니다.

씨앗의 이름
Naming the Seed

3주간 발굴한 나의 원천 텍스트를 가장 간결한 기호로 압축하는 작업. 독자의 언어로 건네졌을 때, 그 한 단어·한 문장이 즉각적으로 메시지를 전달할 수 있어야 한다. 이것이 문법 파트의 완성이자, 논리 파트로 넘어가는 출발점이다.

좋은 기호는 심플합니다. 선 몇 개, 형상 하나. 그런데 그것을 보는 사람은 설명을 듣기 전에 이미 무언가를 감지합니다. 기호의 힘은 거기에 있습니다.

내 씨앗이 설명을 필요로 하지 않는 기호가 된다면, 그것은 누구에게나 가장 간결하게 내 메시지를 전달할 수 있다.

심플할수록, 구체적일수록 좋습니다. 이름 하나, 사물 하나가 보는 순간 '이 사람이 무엇을 하는 사람인지'를 전달한다면 — 씨앗은 이미 기호가 되기 시작한 것입니다.

문법 파트의 완성 구조

원천 텍스트 발굴 → 목소리·결 탐색 → 콘텐츠 지형도 작성 → 씨앗의 이름 짓기. 여기까지가 문법이고, 이 이름을 가지고 구조를 세우는 것이 논리다.

3

오병이어 — 오토파지의 마지막 관문

강의는 오병이어 이야기로 마무리됩니다. 보리떡 다섯 개와 물고기 두 마리. 굶주린 군중 앞에서 어린아이가 내어놓은 것. 그것을 나누었더니 모두 먹고도 열두 광주리가 남았습니다.

콘텐츠를 만들고 지키려는 사람은 열두 광주리를 먼저 계산하기 시작합니다. 그런데 열두 광주리부터 계산하면 기적은 일어나지 않습니다. 순서를 바꾸는 것 — 먼저 내어놓는 것 — 이것이 오토파지의 마지막 관문입니다.

움켜쥔 손의 논리

  • 내 철학을 지키려면 경계가 필요하다
  • 내 콘텐츠를 아껴야 가치가 유지된다
  • 먼저 구조를 짜서 이윤을 확보해야 한다
  • 지금은 아직 나눌 때가 아니다

펼친 손의 논리

  • 지식 콘텐츠는 AI 시대에 무료화된다
  • 내어줄수록 관계와 신뢰가 쌓인다
  • 아낌없이 나누고, 남은 것은 연결이다
  • 죽는 것 같지만, 이렇게 사는 것이다
오토파지의 끝

내어놓는 행위를 먼저 하는 것. 내 씨앗을 애지중지 지키는 것이 아니라, 물처럼 바람처럼 흐르게 하자. 나누고 더 풍요로워지는 삶을 경험하자.

4

디퍼 OS — 창작자의 에이전트 시스템

오늘은 한 달 내내 곁에 있던 사막여우의 바탕, '디퍼 OS'를 함께 봅니다. Claude Code + Obsidian(볼트)을 연결하는 창작자 전용 에이전트 시스템입니다. 비개발자도 설치할 수 있는 데스크톱 앱 버전이 나오면서 진입 장벽이 낮아졌습니다.

에이전트
Agent (Claude Code)

머리(생각)뿐 아니라 손발(실행)까지 달린 AI. 대화창이 머리만 쓰는 것이라면, 에이전트는 직접 파일을 열고, 분석하고, 저장하고, 다른 프로그램과 연동하며 일을 완수한다. 내 C드라이브를 서버로, Obsidian 볼트를 DB로 쓰는 1인 창작자 시스템.

대화창 · Claude.ai

  • 무료 사용 / Pro 구독 선택
  • 텍스트·파일·이미지 입력 지원
  • 프로젝트로 맥락·지침 저장
  • 모바일·태블릿·PC 모두 사용
  • AI가 답하면 사용자가 직접 적용

코워크 · Cowork

  • Pro 구독 필요
  • 내 컴퓨터 폴더를 직접 읽고 쓰기
  • 파일 생성·수정·저장을 AI가 수행
  • Dispatch로 핸드폰 원격 지시 가능
  • 외부 앱 연동은 제한적

클로드 코드 · Claude Code

  • Pro 구독 필요
  • 로컬 파일 시스템 전면 접근
  • MCP 커넥터로 외부 앱 연동
  • 여러 에이전트 동시 운영 가능
  • Obsidian·웹사이트·SNS 연결

세 도구는 층위가 다릅니다. 대화창이 AI와 나누는 대화라면, 코워크는 내 컴퓨터 안에서 직접 일하는 AI입니다. Claude Code는 한 걸음 더 나아가, 여러 에이전트가 서로 협력하며 생각하고 실행하는 팀을 꾸립니다. 입문은 대화창으로 충분하지만, 반복되는 작업을 자동화하고 싶다면 코워크와 Claude Code가 실질적인 도구가 됩니다.

디퍼 OS를 쓰면 달라지는 것

Obsidian 볼트에 모닝 페이지와 원고를 쌓아두면, Claude Code 에이전트가 이를 읽어 분석하고 편집한다. 지침에 따라 SNS 초안을 만들거나 웹사이트에 글을 자동 발행하는 것도 가능하다. 컴퓨터를 켜둔 채 외출해도 핸드폰으로 에이전트에게 지시를 내릴 수 있고, 돌아오면 지시한 일이 완료돼 있다. 내 로컬 컴퓨터가 서버가 되고, 별도의 서비스 비용 없이 운영되는 1인 창작자 전용 자동화 시스템이다.

5

퍼실리테이터 공동체 — 하나의 제안

문법 수료와 함께, 하나의 제안을 내어놓습니다. 디퍼 언브랜딩살롱의 문법 4주 과정을 함께 수익화하는 커뮤니티 문화를 만들자는 것. 뼈대는 드리되, 각자의 개성으로 번역해서 운영하는 방식 — 살롱이 생태계처럼 움직이게 하자는 구상입니다.

각자 자유롭고 온건한 삶을 택하지만, 다음 시대를 위해 무언가를 남기고 싶은 사람들. AI가 아무리 뛰어나도 인간의 연결되는 감각을 되돌려줄 수 있는 공동체.

디퍼 커뮤니티 비전

제안의 구체적인 그림은 이렇습니다. 수료자가 직접 '문법 파트 4주 살롱'을 운영하고, 그 수강생들은 디퍼 커뮤니티로 연결됩니다. 가르치면서 공부가 되고, 팬덤을 모으면서 관계가 쌓입니다. 커뮤니티 안에서 저자·강사·독자가 레이어별로 연결되는 구조입니다.

퍼실리테이터의 역할

  • 문법 파트 4주 살롱 운영
  • 각자 개성으로 번역·운영
  • 월간 디브리프 및 꿀팁 공유
  • 케이스 공유로 상호 개선
  • 디퍼 커뮤니티 내 홍보 연대

공동체 생태계

  • 저자 · 강사 · 창작자 · 독자 연결
  • AI 기반 출판 + 학습 병행
  • 책 한 권이 브랜드가 되도록
  • 읽고 · 쓰고 · 배우고 · 가르치기
  • 함께 살아남는 커뮤니티
