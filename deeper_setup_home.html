먼저, 이 한 장만

톡방에 여러 글이 올라와 뭐가 진짜 매뉴얼인지 헷갈리셨죠. 여기 순서대로만 하면 됩니다. 다른 글은 안 보셔도 지장 없어요.

오늘 할 일

딱 하나 — obsidian.md에서 옵시디언 설치

그거 하나면 오늘은 충분합니다. 나머지는 다음에, 천천히.

설치, 딱 4단계

전체 20~25분
1

옵시디언 설치 → 내 노트 폴더(볼트) 만들기

글이 텍스트 파일로 쌓이는 바닥을 만듭니다.

7분
2

클로드 데스크탑 앱 설치 → 위쪽 Code 탭 열기

사막여우가 작동하는 자리예요.

5분
3

1단계 폴더를 Code 탭에 연결 (Select folder)

AI가 내 노트를 보게 “이 폴더에서 일해”라고 가리켜 줍니다.

3분
4

Code 탭 안 터미널에서 세 줄 명령으로 사막여우 설치

매일의 루틴·질문이 깔립니다.

10분

각 단계의 정확한 클릭 순서·화면은 정본 상세 가이드 2부 ‘설치하기’에 그대로 있습니다. 한 번에 다 안 하셔도 됩니다.

설치 끝난 뒤, 이번 주는

안녕

아침에 채팅창에 안녕 한 마디 — 오늘 노트와 질문 하나가 만들어져요. 답을 한 줄 적으면 끝.

적은 글은 옵시디언에 자동 저장되니 이번 주는 다른 걸 안 하셔도 안 사라집니다. 오아시스·밤하늘·백업 같은 말은 익숙해지면 그때 하나씩. 지금은 몰라도 괜찮아요.
