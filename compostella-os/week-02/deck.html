설치 전 세 가지

쓰는 AI와 내 자료 폴더를 알려주세요

설치 환경필요한 실행 프로그램은 고슴도치가 확인합니다.
내 자료 폴더Obsidian 볼트가 있는 폴더를 알려줍니다.
사용 환경Codex 또는 Claude Code 중 지금 쓰는 환경으로 시작합니다.

비공개 강의실 ZIP

압축을 풀고 그 폴더를 엽니다

Windows탐색기에서 ZIP 압축을 푼 뒤 `compostella-os` 폴더를 Codex 또는 Claude Code로 엽니다.
macOSFinder에서 ZIP을 풀고 같은 폴더를 사용 중인 에이전트 환경에서 엽니다.

공개 페이지에는 ZIP 다운로드 링크가 없습니다. 인증된 강의실에서 받습니다.

설치 요청문

설치는 고슴도치에게 맡기세요

고슴도치, 지금 쓰는 AI 환경에 콤포스텔라를 설치해줘. 내 Obsidian 볼트는 [폴더 경로]야. 기존 자료를 보존하면서 설치하고 정상 작동하는지 확인해줘. 내가 결정할 문제가 생기면 알려줘. 끝나면 경영실을 열어줘.

구독과 비용

현재 구독 범위에서 시작합니다

설치 자체는 별도 API 키나 사용량 기반 API 결제를 요구하지 않습니다. 다만 Codex와 Claude Code의 구독 한도는 각 서비스 정책을 따르며 무제한을 보장하지 않습니다.

도구 준비필요한 도구는 고슴도치가 준비합니다. 추가 계정이나 비용이 필요하면 먼저 알려드립니다.
준비 확인내 환경에서 실제로 사용할 수 있는지 확인하고 첫 업무로 이어갑니다.

현재 화면에서 실제로 되는 일

내 사업의 현재 위치가 보입니다

오늘 볼 수 있는 것내 사업과 자산, 나를 돕는 역할, 이번 주 할 일과 실제 결과가 한곳에 모입니다.
사업에 맞춰 연결할 것회계·결제·SNS 등 외부 서비스는 별도 연결이 필요합니다. 필요한 순서와 범위를 고슴도치와 정합니다.

화면의 가상 시간·재무 예시는 실제 사업 실측과 구분합니다.

후원본 source·수정본 artifact·원문 대조 check와 수정 이유 decision을 연결합니다.

도장은 파일과 검사를 확인합니다. 저자 의도를 살렸는지는 대표가 원자료를 읽고 판단합니다. 그 판단이 다음 일의 초기값이 됩니다.
