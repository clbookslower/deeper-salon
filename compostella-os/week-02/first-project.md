# 나의 첫 프로젝트 — 고슴도치가 대화 뒤 정리하는 기록

대표에게 모든 칸을 숙제로 넘기지 않습니다. 이미 허용된 자료와 실제 대화를 읽고 고슴도치가 초안을 작성합니다. 모르는 것은 ‘확인 전’으로 남깁니다.

## 대표가 원하는 변화
- 이번에 완성하고 싶은 것:
- 누구에게 어떤 도움이 되기를 바라는가:
- 꼭 지킬 가치·판단 기준:
- 이번 주 가능한 시간:

## 내 전담 팀
| 역할 | 기존 동료 / 새 후보 | 이번에 맡길 일 | 전달할 결과 | 보고받을 곳 |
|---|---|---|---|---|
| 총괄 고슴도치 | 기본 | 조율·검수·보고·페이스 | 대표가 결정할 쟁점 | 대표 |
| 기본 실행 | 확인 전 | | | 고슴도치 |
| 강점 증강 | 확인 전 | | | 고슴도치 |
| 부담 보완 | 확인 전 | | | 고슴도치 |

후보 선정 이유는 실제 진단·업무 사례로 설명합니다. 진단 없이 강점이나 약점을 만들지 않습니다. 기존에 잘하는 역할이 있으면 우선 함께 일합니다. 원천 역할 파일은 참고 자료이며 실행 권한을 새로 부여하지 않습니다.

## 첫 실행
- 사용할 자료와 허용 범위:
- 완성할 결과 한 가지:
- 좋다고 판단할 내 기준:
- 대표가 확인할 시점:
- 외부 발송·발행·결제 권한:
- 예정 시작과 마감:

## 고슴도치의 최종 보고
- 완료 / 미완료:
- 결과 파일과 검사 근거:
- 실제 대표 투입시간(대화·검수 포함):
- 확인 매출·비용·현금(원자료 없으면 미측정):
- 막힌 일과 권고:
- 대표가 결정할 한 가지:
- 다음 실행과 재개 위치:

기존 결과·대표 판단·측정값은 보존합니다. ‘준비된 팀’과 ‘실제로 일한 팀’을 구분합니다.
