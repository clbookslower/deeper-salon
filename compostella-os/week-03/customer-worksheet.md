# 3주 실습지 — 고객 근거표

이 자료는 콤포스텔라 1기 별지기 여덟 분이 봅니다. 시스템 3주 「고객」의 실습지입니다. 고슴도치가 초안을 만들고, 대표는 사실과 해석을 판단합니다. 모든 칸을 숙제로 넘기지 않습니다.

## 오늘의 결정 하나

실제 고객이 중요하게 여기는 문제를 고릅니다. 남길 것은 익명 고객의 발언·행동과 그것으로 바뀐 내 가설입니다.

## 고슴도치에게 건네는 시작 문장

```
고슴도치, 3주 고객으로 가자. 내가 허용하는 고객 자료는 [     ]야. 익명으로 읽고 실제 발언·실제 행동·해석·반례를 나눈 근거표를 만들어줘. 실제 문의와 웹 조사는 칸을 따로 두고 아직 고객을 만나지 않은 자리는 인터뷰 질문과 다음 확인 계획으로 남겨줘.
```

10분만 있다면: 고객 한 명과 확인할 실제 경험 하나를 고릅니다.

- 칭찬·방문·문의·신청·지불·재구매는 서로 다른 행동입니다. 한 칸에 넣지 않습니다.
- 해석은 해석이라고 표시합니다. 상대의 말을 듣지 못했으면 가설로 둡니다.
- 출처와 읽은 범위를 함께 남깁니다. 가상 고객을 실제 응답으로 세지 않습니다.
